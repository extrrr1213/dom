# 3D-модель участка

Как запустить, ходить по участку и пересобрать — в [README в корне репозитория](../README.md).

Коротко: `npm install && npm start`, затем кнопка «Прогулка».

| Файл | Что внутри |
|---|---|
| `scene.js` | сцена three.js: дом, террасы, участок, окружение, солнце, камеры, прогулка |
| `scene.json` | геометрия из `../plan.py` (не править руками) |
| `page.html` | интерфейс: ракурсы, солнце, кнопка «Прогулка» |
| `build.mjs` | собирает `dist/index.html` (CDN), `dist/local.html` (офлайн), `dist/render.html` (для кадров) |
| `serve.mjs` | локальный сервер на порту 5173, без зависимостей |
| `render.mjs` | рендер кадров в PNG через Chrome/Playwright |
