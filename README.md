# Участок на ул. 1905 года (Одинцово, ИЖС 4.5 сот.)

Планировка участка и дома DP-Module «Модерн» (7 модулей, 122.5 м²), а также 3D-модель, по которой можно ходить от первого лица.

Текущий вариант — **зеркальный**:
- мастер-блок стоит с южной стороны, жилая зона — у дороги;
- парковка на 2 машины друг за другом идёт вдоль северного забора: бетон от забора до стены дома, въезд через ворота;
- спортплощадка в юго-восточном углу, детская зона в юго-западном.

| Что | Где |
|---|---|
| 2D-схема (размеры, отступы 3 м, площади) | `plan.py` → `plan.svg` (`plan.png` — её картинка) |
| 3D-модель и прогулка | `render3d/` |
| Готовые кадры | `render3d/renders/*.png` |

## Запустить 3D и походить по участку

Нужны [Node.js](https://nodejs.org) 18+ и git.

```bash
git clone https://github.com/extrrr1213/dom.git
cd dom
git checkout claude/serene-carson-q9lfvg
cd render3d
npm install
npm start
```

`git checkout` нужен, пока изменения не влиты в основную ветку. `npm install` ставит three.js и (для рендера кадров) playwright-core, браузер он не скачивает. `npm start` собирает страницу, запускает сервер и открывает её в браузере: после `npm install` это офлайн-версия http://localhost:5173/dist/local.html (three.js из `node_modules`), без него — http://localhost:5173/dist/index.html (three.js с CDN). Python для этого не нужен. Сервер работает, пока открыт терминал; остановить — `Ctrl+C`.

Если порт 5173 занят (например, другим проектом на Vite), запустите `npm start -- 5174` и откройте адрес с этим портом.
С телефона в той же Wi‑Fi сети: `http://<IP компьютера>:5173/dist/index.html`. Windows может спросить разрешение для Node.js в брандмауэре.

Затем нажмите **«Прогулка»** внизу экрана.

| Действие | Компьютер | Телефон / планшет |
|---|---|---|
| Идти | `W` `A` `S` `D` или стрелки | левый палец — джойстик |
| Смотреть | мышь (сначала кликните по сцене, `Esc` — отпустить мышь) | правый палец |
| Бегом | `Shift` | джойстик до упора |
| Выйти из прогулки | кнопка «Выйти» вверху | кнопка «Выйти» |

Прогулка начинается у калитки, лицом к входу. Сквозь дом, машины, бассейн, деревья и заборы пройти нельзя. На террасы можно подняться. Калитка открыта, через неё можно выйти на улицу. Откатные ворота во время прогулки закрыты: открытое полотно заезжает за калитку.

Другие возможности страницы:
- ракурсы: «С дрона», «Задний двор», «У бассейна», «Въезд», «С улицы», «План сверху»;
- ползунок солнца (время суток) и месяц: май, июнь или сентябрь. Тени считаются по реальному положению солнца для Одинцово (55.68° с. ш.).

Версия `dist/index.html` берёт three.js с CDN (cdn.jsdelivr.net), поэтому ей нужен интернет. Если CDN недоступен, страница через 20 секунд предложит перейти на `dist/local.html`: там three.js из `node_modules`, интернет не нужен.

## Изменить расстановку

1. Поправьте `plan.py`: размеры дома, комнаты, террасы, парковку, бассейн и т. д.
2. Выполните `python3 plan.py` (на Windows — `py plan.py`), сторонние пакеты не нужны. Он перерисует `plan.svg` и выгрузит геометрию в `render3d/scene.json`. `plan.png` — растровая копия `plan.svg`, её `plan.py` не обновляет.
3. Выполните `cd render3d && npm run build` и обновите страницу в браузере.

Внешний вид 3D (материалы, окна, деревья, соседи, камеры) задаётся в `render3d/scene.js`, интерфейс — в `render3d/page.html`.

Кадры в высоком качестве: `npm run serve` в одном терминале, `npm run render` в другом. Нужен установленный Google Chrome или переменная `CHROME_PATH`. Кадры сохраняются в `render3d/renders/`.
